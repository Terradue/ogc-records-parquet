ogc-records-parquet¶

Store PySTAC OGCRecord objects in Arrow and GeoParquet, with typed columns for queries and a serialized document for reconstruction. Records may have null geometry and need not have a STAC temporal extent.

The package uses pystac-ext-ogc-record for record parsing and serialization. It requires Python 3.11 or newer; the repository test matrix covers Python 3.11–3.15.

Scope¶

The library converts records and stores local Parquet files. Query execution, OGC profile validation, reprojection, and application-specific metadata mapping belong to the calling application.
